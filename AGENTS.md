# dagaroost — Agent Instructions

dagaroost (Dagaroo Smoke Test) is a CCC project that exists only to
smoke-test CCC delegate capabilities: spawn, messaging, park/go,
recycle, resume, remote control and usage, for every vendor CLI.

## Seats

Inert test delegates. They do no substantive work; they answer what
they are sent so the platform can be exercised end to end.

- `dummy`: Claude
- `dummx`: Codex
- `dummg`: Grok

Plus the mandatory `liaison` and `ccc`. Read your own
`ai/agents/<name>/role.md` first.

## Conventions

- Tenets (global, all projects): `~/.claude/rules/tenets.md`.
- Work tracking: `ccc-bd ready --assignee=<your agent>`.
- Messages carry a `[f=…;…;m=…]` header. Reply to `f` with `--re <m>`.
- Never commit secrets. Keep files portable.
